# Guest

This repository now hosts **Kali Fundamentals Lab** - a one-click, Docker-based,
TryHackMe-style Linux room built for eJPT v2 preparation.

- Lab source and instructions: [`kali-fundamentals-lab/`](kali-fundamentals-lab/)
- Downloadable archive: [`kali-fundamentals-lab.zip`](kali-fundamentals-lab.zip)
- Answer key (spoilers): [`kali-fundamentals-lab/SOLUTIONS.md`](kali-fundamentals-lab/SOLUTIONS.md)

Quick start on a Kali VM:

```bash
cd kali-fundamentals-lab
chmod +x setup.sh && ./setup.sh
# then open http://localhost:5000
```
